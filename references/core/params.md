# 采样参数与分辨率

## 1. 官方推荐值

| 参数 | 官方推荐 | 说明 |
| :--- | :--- | :--- |
| 分辨率 | 总像素 **1M / 1.5M / 2M**，可外推 0.25M（512×512）~ 4M（2K） | 宽高必须是 **16 的正整数倍**，否则报错 |
| 长宽比 | 任意 | Gradio 会自动对齐到 16 倍数；手填尺寸要自己对齐 |
| Steps | **≥ 50** 效果最佳 | 见 §3 的两档取舍 |
| CFG | **3.0**（区间 3.0–6.0） | 长 prompt 用 3.0；短 prompt 适当调高 |
| Shift | **5.0** | — |
| Sampler | **Flow-matching Euler** | — |
| SLG | 两种：标准 SLG（scale 3, range 0.01–1.0）；二次采样 SLG（`uncond skip`，skip layer **22**，22/24/26 皆可） | Python API 里是 `uncond_skip_layers=[22]` |
| 负面提示词 | Python API 默认为**空** | 官方另给了一组推荐负面 tag，见 `negative.md` |

官方唯一一句关于机制的原话，**整套参数观都建立在这句上**：

> Turning off SLG will make the output image look very realistic, but it may also cause some details to collapse.
> 关闭 SLG 会使输出的图像非常真实, 但是可能会造成细节的崩坏.

## 2. 两档配置

| | **档 Q（质量档，默认）** | **档 R（写实快档）** |
| :--- | :--- | :--- |
| 分辨率 | 1M~2M | 0.6M |
| Steps | 50 | 16~30 |
| CFG | 3.0 | 3.0 |
| SLG | 开，`uncond_skip_layers=[22]` | 关 |
| 产出特征 | 小字、窗框、书页、百褶裙这类高频几何边缘收敛得好；细节不易崩 | 真实感更强；细节（手、眼、图案、文字）容易塌 |
| 需要什么补偿 | 不需要堆防崩词 | 必须配 `photo.md` 里标 `[R]` 的防崩与固化词 |
| 典型用途 | 交付图、有文字、有多人 | 快速试构图、追求胶片真实感 |

**规则与档位绑定。** `photo.md`、`anime.md` 里每条规则后面标了 `[Q]`、`[R]` 或 `[Q,R]`：`[R]` 条目是关 SLG 后细节崩坏的人工补偿，跑档 Q 时不用堆；反过来说，档 R 下省掉 `[R]` 条目，手和五官就会崩。

官方另有一句面向 Base 的提醒：Base 没有对 CFG 等推理参数做蒸馏，参数不合适效果会明显变差。这不是「玄学调参」，是模型本身的状态。

## 3. 维度速查表

全部为 16 的倍数。总像素在目标值 ±10% 内都算正常。

| 比例 | 0.6M（档 R） | 1M | 1.5M | 2M |
| :--- | :--- | :--- | :--- | :--- |
| 1:1 | 768×784 | 1024×1024 | 1248×1248 | 1456×1456 |
| 4:3 | 896×672 | 1152×864 | 1392×1040 | 1632×1248 |
| 3:4 | 672×896 | 864×1152 | 1040×1392 | 1248×1632 |
| 3:2 | 960×640 | 1248×832 | 1536×1024 | 1792×1200 |
| 2:3 | 640×960 | 832×1248 | 1024×1536 | 1200×1792 |
| 16:9 | 1024×576 | 1360×768 | 1664×928 | 1920×1088 |
| 9:16 | 576×1024 | 768×1360 | 928×1664 | 1088×1920 |
| 2:1 | — | 1440×720 | 1728×864 | 2048×1024 |

用法：先定比例，再按「有没有文字」选 1M 或 1.5M。**不要出现 1080 这种非 16 倍数的边。**

## 4. 按文字密度调

| 文字情形 | 分辨率 | Steps | SLG |
| :--- | :--- | :--- | :--- |
| 无文字 | 1M | 50 | 开或关都行 |
| 中等字号（对话框、字幕、卡牌数值、海报大标题） | 1M | 50 | 开 22 更稳 |
| 整页密集小字（多栏正文、试卷、说明书） | ≥ 1.5M，字高至少 40px | 50 | 必须开 22 |
| 只要真实感、不在乎字 | 0.6M | 16~30 | 关 |

判断字高的土办法：目标字高（px）≈ bbox 高度 ÷ 行数。低于 24px 的汉字基本会糊。

## 5. 参数与提示词的相互影响

- **CFG 越高，负面提示词的权重越大。** 负面词很长时（几百词），CFG 拉到 5~6 容易把画面推向过度平滑或过度规避；保持在 3.0 更安全。
- **步数越低，越依赖提示词把细节写死。** 档 R 下不要写「auto」「natural」「whatever」这类放权词。
- **分辨率越高，同一条提示词的主体占比越小。** 从 1M 换到 2M 时，全身边长要补景别词，否则人物会在画面里显得更小、背景抢戏。
- **SFT 版与 Base 版不是同一组最优参数。** 官方对比中 SFT 的文字分组与排版更规整；如果你用的是 SFT 或社区蒸馏版（8 步 DMD 等），先按该模型卡给的参数跑，再回来套本 skill 的提示词规则。

## 6. 可复现

固定 Seed 时：

1. 提示词只改**出错的那一项**，不要顺手润色别的句子。
2. 负面提示词一个字符都不要动（CFG 的采样方向是 positive − negative，改负面词等于改全图走向）。
3. 改动量控制在几十 token 内；大幅增删前面的句子会整体位移后面的内容，人脸和发型会变。
4. 每次出图记录：`正面/负面/尺寸/Steps/CFG/Shift/SLG/Seed/档位`。没有记录的对照不算实测。

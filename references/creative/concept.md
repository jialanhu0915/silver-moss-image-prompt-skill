# 视觉创意：先发明画面，再写提示词

> 本文件关于「什么算好创意」「模型能执行多复杂的概念」的判断，是作者品味与工作经验，除标注者外均为【未验证】，不是模型事实。证据分级见 `diagnostics/sources.md`。

编译层解决「写得对不对」，本文件解决「值不值得画」。两者分开：先选定一个概念，再交给 `core/caption.md` 与 `styles/*` 写成可见描述。

## 1. 何时进入

| 信号 | 处理 |
| :--- | :--- |
| 只给主题、一句话、开放式创作 | 进入，按 §2 判模式、§2.1 定强度 |
| 明确要概念图、海报、封面、奇观、记忆点 | 进入 |
| 用户给了完整画面（构图、光、主体位置都点了名） | 只走 §9，不重新发明 |
| 改字、复现参考图、商品图、技术示意、证件照式人像 | 跳过，按 `core/caption.md` §4.1 保真润色 |
| 用户要的就是「普通的图书馆」 | 跳过；「普通」本身是需求 |

判据是需求的开放度，不是字数。一百字的普通需求仍然普通，八个字也可能已经指定了全部关键选择。

## 2. 三档模式

| 模式 | 触发 | 可改 | 不可改 |
| :--- | :--- | :--- | :--- |
| **忠实** | 用户给了具体画面，或说「别改我的构图」 | 语序、主次、可见化 | 构图、光色、主体选择 |
| **增强**（默认） | 给了主体 + 场景类型，画面另有留白 | 场景关系、空间规则、道具、光 | 主体、数量、关系、场景类型、排除项 |
| **自由** | 只给主题，或明说要大胆 | 场景、隐喻、空间规则可重设 | 主题、用途、排除项 |

- 用户一句「别改我的构图」即降到忠实，不必追问；用户说「要出彩」「要记忆点」即升到自由。
- 模式不写进交付物（`SKILL.md` 已规定不加与提示词无关的说明），除非用户问。
- 模糊时选增强，把选择写成可见事实；不确定的取舍在正文里做成一贯方案，而不是两头讨好。

### 2.1 创意强度（与模式正交）

模式回答「能改用户多少」——哪些用户给定的内容允许被重设计；强度回答「奇观预算多大」——在允许的范围内可采取多大胆的表现，以及最多投入多少导演决策与机制。两者分开判，同时约束结果：忠实模式也可能要一张压迫感很强的人像（模式=忠实，强度=强化），自由模式也可能只要一张极简图（模式=自由，强度=克制）。

| 强度 | 默认触发 | 机制数 | 不可能元素 | 空间规则 | 必须做到 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **克制** | 没要奇观：纪实、商品、日常、极简 | 1 | 0~1 | ≤1 | 主焦点 + 落地三件套（§8.1） |
| **强化**（默认） | 有情绪或记忆点要求 | 1 主 + 1 辅 | 1 | ≤2 | 辅机制只能强化主视觉，不得另立焦点 |
| **奇观** | 明确说震撼 / 宏大 / 史诗 / 主视觉海报 | 1 主 + 2 辅 | 1~2，同一主题 | ≤2，且由一条空间规则统一 | 尺度层级 + 视点 + 「正在发生」的证据（§8.3） |

- **默认不进奇观档。** 用户没说震撼，就把普通需求做成清晰的图，不靠加压取胜。
- **档位由用户的话决定，不由你的兴致决定。** 「游戏封面」「别太素」算强化；「第一眼觉得不可思议」「宏大」「史诗级」才算奇观。
- **提高强度不等于取消主次。** 奇观档的上限从「元素个数」换成「层级服从」：三个机制必须共同解释同一个主视觉，且能由一条空间规则说明。做不到就退回强化。

## 3. 先固化不可动的部分

写任何新元素之前，把这几项抄成一行：主体、数量、关系、场景类型、媒介 / 画风、必须出现的文字、排除项、现实约束（「必须是真实大学图书馆」「服装不能改」）。

创意与约束冲突时按 `direction/brief.md` §4 的优先级处理（用户要求 > 既有画面 > 任务功能 > 创意钩子 > 美术优化）。只报一句取舍，不辩护。用户没指定、但你自己加的设定不算约束——下一轮可以推翻。

## 4. 定主题三角

1. **用途**：海报 / 封面 / 叙事插画 / 概念图 / 角色设定。
2. **情绪**：观众应该被压住、被逗乐、被安慰，还是只被告知。
3. **第一眼**：合上眼能记住的那一个东西是什么。

后面每个取舍都拿这三项当裁判：不服务主焦点的元素，无论多好看都删。

## 5. 创意机制

七条常用机制。每条都要求**可见、可指认**；机制名只给你自己看，不进 caption。

| 机制 | 定义 | 可抄示范 | 失败长相 |
| :--- | :--- | :--- | :--- |
| **尺度反转** scale reversal | 熟悉物体换一个量级，且与人有接触关系 | `a doorknob the size of a car, its owner's hand resting on it` | 只是「巨大的 X」悬在天上，没有人或参照物建立比例 |
| **规则错位** rule displacement | 只改一条物理或生物规则，其余照常 | `rain falling upward past the windows while umbrellas stay dry` | 一次改三四个规则，画面没有一条能读出来 |
| **意象具象化** concretized metaphor | 抽象概念变成一件可触摸的东西 | `a city folded into a sealed paper letter, the fold lines still creased` | 写「孤独」「记忆」本身，等模型自己找图形 |
| **反常主体—环境关系** symbiosis | 主体与场景互为建造者、寄生者或器官 | `the castle is the spine of a sleeping dragon, its windows glowing with each breath` | 主体只是「站在前面」，背景再换也不影响关系 |
| **时间凝固** frozen instant | 停在一个正在发生、值得追问的瞬间 | `the exact frame where the glass begins to crack but has not yet fallen` | 写「动态」「动感」这类形容词，没有具体瞬间 |
| **媒介转化** medium crossover | 两种材质或画风的接缝本身成为主角 | `a screen-printed ochre shadow slipping out of its green outline, the misregistration visible along the rim` | 两种画风各占一半、中间糊成渐变，没有统一的光 |
| **单一不可能元素** single impossible element | 只有一件事违反常理，其余全部落地 | `one chair floating a hand's width above the floor, its shadow still on the boards` | 不可能元素铺满画面，尺度、光向、投影全不成立 |

- 一张图只用一条**主**机制；机制总数按强度分配（§2.1）：克制 1 条，强化 1 主 + 1 辅，奇观 1 主 + 2 辅。无主次的并列仍会互相抵消。奇观档的例外条件见 §2.1 与 §8.3：三个机制必须由同一条空间规则统一，做不到就退回强化。
- 海报与平面类另有钩子来源，见 §8。

## 6. 一次机制改写

定下首选概念后，强制问一句：

> **能不能只改一条规则，让主体和场景产生新关系？**

「改规则」是让两件事互相定义；「加装饰」只是往同一件事上加东西。

| 原始想法 | 加装饰（不改关系） | 改一条规则（改关系） |
| :--- | :--- | :--- |
| 女孩在图书馆看书 | 加台灯、加飘浮尘埃、加落地窗、加夕阳 | 闭馆后只剩她手机灯那一圈光，光圈边缘把整排书架的竖线切断，其余书库退回黑暗 |
| 巨龙盘踞城堡 | 加大、加火焰、加雷电、加军队 | 城堡是巨龙沉睡时形成的脊椎，窗户随呼吸明灭 |
| 少女站在城堡前 | 加旗帜、加飞鸟、加晚霞 | 城墙的影子倒着落到天上，她站在影子投下的那块地面里 |

只有自由模式，或用户明确要多个方向时，才并列 2–3 个候选；否则选一个做到位。

**注意**：机制改写不得越过 §3 的固化清单。用户点了名的主体、场景类型、服装、文字都不能为了机制而改。

## 7. 淘汰判据

**硬判据**（命中即重构）：

1. 一句话说不清那个视觉现象。
2. 去掉「史诗 / 震撼 / 超现实 / 电影感」之后，画面不再特殊。
3. 需要观众同时看四个以上互不相让的焦点。

**软判据**（可以留，但要写清楚）：

1. 与 §4 的主题三角不一致——画面很酷，但不是这张图要干的事。
2. 与通道冲突——写实通道里放不可能物理，应显式改走混合（`styles/hybrid.md`），不要偷偷混。

**套路组合不是禁词。** 下面这些搭配用户经常就是要它，处理方式是「用了就改一条规则」，不是拒绝（本表是作者品味，【未验证】）：

| 常见搭配 | 改一条规则的方向 |
| :--- | :--- |
| 未来城市 + 霓虹 + 雨夜 + 飞行汽车 | 让城市的一层可见地「过期」：旧招牌与全息投影在同一面墙上争夺位置 |
| 奇幻森林 + 发光蘑菇 + 薄雾 + 精灵 | 让光源成为生物：照亮路径的是会移动的东西，而不是散落的光点 |
| 巨大月亮 + 孤独人物 + 海边 + 逆光 | 让月亮有物理后果：潮水退到异常远，人站在原本是海的地面上 |
| 机械人 + 破败城市 + 火焰 + 电影感 | 让破坏有方向：所有残骸都朝同一个点倒塌，而那里空着 |

## 8. 执行预算

概念越奇观，越要控制画面里同时成立的东西。以下为工作经验【未验证】，但按它写通常更容易出可读的图。

### 8.1 落地三件套（三档都要）

1. **尺度参照物**：人、门、车、树——没有参照物，巨物只是大块颜色。
2. **统一光向**：全图一套主光；两套方向不同的光会让奇观退回拼贴。
3. **接触与投影**：不可能的东西必须与真实表面接触，并在上面留下影子；缺这项，主体会变成贴图。

### 8.2 按强度分配预算

| 强度 | 做法 | 别做 |
| :--- | :--- | :--- |
| 克制 | 主焦点 + 一个可见关系；其余按常规写 | 加第二层空间规则、加第二个不可能元素 |
| 强化 | 主机制 + 一个辅机制（同一主题下）；辅机制用光、材质或尺度强化主视觉 | 辅机制另立一个焦点（例如巨龙氛围里又加了飞行船队） |
| 奇观 | 主视觉 + 两个辅机制，三者共享一条空间规则；尺度层级写明；用一个细节证明关系正在发生 | 三个机制各说一件事；只在抽象名词上成立；假设模型会自己补全空间 |

- **空间规则最多两层**（「上下颠倒」+「同一时刻」已到顶）。再多，观众读不出来，模型也会糊。
- **文字、精细几何、机械结构**仍走保守路线（`core/text-in-image.md`）；要用 Layout 精确落位时先读 `core/layout.md`，它是实验性的。
- **抽象名词不进 caption**：写图形，不写感受（`craft/aesthetics.md` §9–10）。

### 8.3 奇观档的追加要求

通用六问见 `direction/brief.md` §2；强度=奇观时全答，不删减，并额外做到：

1. **尺度层级可分**：前景有已知尺寸的参照物，中景是主体，远景交代环境。
2. **一个正在发生的证据**：同步明灭的灯、正在退去的潮水、被推开的雪或尘。
3. **一条空间规则**解释全部异象（§8.2）；解释不了就减一个机制。
4. **视点有理由**：仰拍给压迫、俯拍给规模、平视给在场，不凭习惯选。

### 8.4 平面类分支（海报 / 封面 / 版式图）

不需要不可能元素，钩子来自版式与印刷行为：标题与图形共用一条边界、两版色套印错位、纸张折痕或裁切线参与构图、小字与大标题争夺同一块留白。判据仍是「一句话能说出这个版面发生了什么」；强度=奇观时，让版面事件承担主视觉，而不是在版面上叠更多装饰。

### 8.5 反例

四个焦点互不相让；三层空间规则叠加；创意只在「孤独」「永恒」这类词上成立；奇观元素没有尺度参照；奇观档却只有一条普通机制（说明强度没落地）。

## 9. 交给编译层

1. 用一句内部语言固定主张：**「谁的什么，正在发生什么，因此和周围是什么关系」**。这句不写进 caption。
2. 映射到 `core/caption.md` §4 骨架：光线与色温 → 媒介、镜头与钩子 → 主体 → 动作与接触 → 场景 → 材质收尾。
3. 按通道取规则：`styles/photo.md`、`styles/anime.md`、`styles/hybrid.md`；镜头、构图、光色按需查 `craft/`。
4. 机制落地成可见事实后，交付物里不应出现机制名、模式名或创作说明。

## 10. 自检

1. 能用一句话说出那个视觉现象吗？
2. 是否只有一个主焦点，其余都在支撑它？
3. 强度档位是否落地——不可能元素有参照物、光向、投影；强度=奇观时，§8.3 四条是否做到？

三条都过，再进入导演层（`direction/brief.md`）。创意走查见 `examples/creative.md`。

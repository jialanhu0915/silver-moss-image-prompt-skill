# 视觉导演：把概念变成画面决策

> 本文件关于「哪种镜头 / 光色更有效」的判断是摄影与设计通行经验，除标注者外均为【未验证】，不是模型事实。证据分级见 `diagnostics/sources.md`。

本层位于创意层之后、编译层之前：`concept.md` 决定画什么，本文件决定观众**怎么看到**它。技巧的具体写法不在本文件，一律查 `craft/`；这里只负责「选哪几项、为什么」。

## 1. 何时进入

| 信号 | 处理 |
| :--- | :--- |
| 概念已定，需要决定构图 / 镜头 / 空间 / 光色 | 进入 |
| 用户已指定构图、机位、光向 | 只做保真编译，不重新导演 |
| 单物体、极简、纯文字改稿 | 跳过，直接编译 |
| 海报 / 封面 / 图文版式 | 进入，并加读 `direction/poster.md` |

判断标准是同一条：**观众需要被引导吗？** 需要就进来，不需要就别加决策。

## 2. 导演简报六问

内部作答，通常不输出给用户。每题右侧是它落到提示词里的大致形态。

| # | 问题 | 决定什么 | 落到提示词 | 查 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 观众第一眼该看什么？应有什么情绪？ | 视觉目标 | 一句话主张，**不写进 caption** | `concept.md` §4 |
| 2 | 主体放在哪？视线怎么走？留白给谁？ | 构图 | 方位句 + 前景形状 + 留白用途 | `craft/composition.md` §1–§4、§10 |
| 3 | 从哪里、多远、什么角度观察？ | 镜头与机位 | 机位高度 + 景别 + 焦段造成的透视 | `craft/camera.md` §1–§5 |
| 4 | 前中后景各承担什么？尺度靠什么读？ | 空间与层次 | 逐层物件 + 遮挡 + 参照物 + 投影 | `craft/composition.md` §3、`craft/camera.md` §2 |
| 5 | 主光从哪来、什么性质？主辅强调色怎么分？ | 光与色 | 光源位置 + 明暗分区 + 三色分工 | `craft/aesthetics.md` §1–§5 |
| 6 | 标题、主视觉、信息区怎么排？ | 版式（仅图文类） | 标题区 + 阅读顺序 + 层级 | `direction/poster.md` |

**六问不必全答。** 答完 1 之后，只挑真正能强化它的 2–5 项（§3）。

## 3. 决策上限：2–5 项

每多一项决策，就多一个可能和别的描述打架的约束。上限按创意强度走（强度定义见 `creative/concept.md` §2.1）：

| 强度 | 决策数 | 典型组合 |
| :--- | :--- | :--- |
| 克制 | 2 | 镜头 + 光向 |
| 强化 | 3–4 | 构图 + 镜头 + 光色 |
| 奇观 | 4–5 | 上述 + 空间层次（+ 版式，若为海报） |

**选择顺序**：先定视觉焦点 → 再定镜头（它决定尺度与压迫感）→ 再空间层次 → 再光色 → 版式放最后。

**删减规则**：

1. 两项服务同一个焦点时，留更可见的那项（`低机位` 比 `对称构图` 更容易被画出来）。
2. 与用户约束冲突的那项直接删，不折中。
3. 说不清「它让观众看到什么」的项，删。

## 4. 约束优先级

冲突时按此顺序，低优先级不得覆盖高优先级：

1. 用户明确的要求与禁止项。
2. 用户已提供的既有画面（草图、成图、版式稿）中必须保留的特征。
3. 任务功能要求：产品可识别、文字可读、全身入画、比例正确。
4. 创意层的核心视觉钩子。
5. 美术指导的可选优化。

只报一句取舍，不辩护。用户没指定、由你自己加的设定不算约束，下一轮可以推翻。

## 5. 六类任务档案

| 任务 | 重点 | 别做 | 首选决策 |
| :--- | :--- | :--- | :--- |
| 人物 / 角色 | 轮廓辨识、姿态、服装可见度、与背景分离 | 背景细节抢注意力；近景裁掉要求的全身 | 镜头 + 光向（轮廓光） |
| 场景叙事 | 动作、视线、环境线索、瞬间张力 | 环境细节各自成焦点 | 构图（视线路径）+ 空间层次 |
| 奇观 / 概念海报 | 尺度、视点、层次、单一钩子 | 多焦点；只在抽象词上成立 | 镜头（低机位/广角）+ 尺度参照 + 光色 |
| 产品 | 轮廓、材质、受控反光、干净背景 | 夸张透视损害识别；复杂概念抢主体 | 光向（按材质选）+ 简洁空间 |
| 海报 / 宣传 | 信息层级、图文关系、留白、文字可读 | 主视觉与标题抢同一块留白 | 版式优先，再定主视觉机位 |
| 复刻 / 高保真 | 保留原构图、机位、色调、主体关系 | 以「优化」为名替换用户选择 | 不做新决策，只补可见化 |

## 6. 从决策到句子

只写可见结果，不写术语名（词表见 `craft/aesthetics.md` §10、`craft/composition.md` §9）。

| 内部决策 | 可抄的写法 |
| :--- | :--- |
| 低机位仰拍 | `camera close to the ground looking up, the towers converging toward the top edge` |
| 主体偏一侧 | `she stands in the right third, the left side left as empty fogged space` |
| 长焦压缩 | `a long lens flattens the distance, the far ridge sitting directly behind her shoulder` |
| 前景框景 | `a blurred archway edge fills both sides, the view passing through it to her` |
| 空气透视 | `far buildings fade and lose contrast while the near edge stays sharp` |
| 冷暖对照 | `cold blue environment, one soft warm lamp on her hands` |
| 尺度参照 | `a doorway beside the hull reaches only a third of its height` |
| 海报留白 | `the upper quarter stays low-detail and low-contrast for the title` |

**语序冲突提醒**：通用提示词经验常建议「先写主体」，本仓库的顺序是**光源句最靠前**（`core/caption.md` §1、`styles/photo.md` §4）。两者不矛盾的做法是：第一句锁光与媒介，第二句立刻给主体——不要把光挪到主体之后。

## 7. 自检

1. 六问里只答了 1 和必要的 2–5 项，没有把六项全塞进 caption？
2. 第一视觉焦点是否清楚，且所有决策都服务它？
3. 镜头与机位是否强化了尺度、压迫感或在场感，而不是只写「电影感」？
4. 前中后景是否可读，奇观是否有尺度参照与接触投影？
5. 光色是否只有一个主光方向、一组明确的主辅强调色？
6. 有没有出现互相打架的决策（对称 + 荷兰角、柔光 + 硬阴影）？

走查见 `examples/creative.md`；海报另见 `direction/poster.md` §10。

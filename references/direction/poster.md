# 海报与图文版式

> 本文件的版式判断来自平面设计通行经验，除标注者外均为【未验证】。字号与像素落位不在本文件：字号估算查 `core/text-in-image.md`，精确坐标查 `core/layout.md`（实验性）。

与 `craft/composition.md` §8 的分工：§8 讲通用图文版面（标题、栏数、留白）；本文件讲海报专属的信息层级、阅读路径与图字关系，不重复其内容。

## 1. 何时用

海报、封面、菜单、信息图、带标题的宣传图。纯插画、无文字的画面不需要本文件。

## 2. 先定层级，再动画面

一张图只允许一个主标题层级：

| 层 | 内容 | 视觉权重 |
| :--- | :--- | :--- |
| 1 | 主标题 / 核心词组 | 最先被看到，字号最大 |
| 2 | 主视觉（图） | 与标题共同承担第一眼 |
| 3 | 副标题 / 一句说明 | 第二眼 |
| 4 | 页脚信息（时间、地址、二维码位置） | 需要时才读 |

层级没定就排字，常见结果是标题和主视觉互相削权，两个都记不住。

## 3. 标题安全区

- 选一块**低细节、低对比**的区域给标题，并在提示词里写出这块区域的存在：`the upper quarter stays low-detail and low-contrast for the title`。
- 标题区不压主体关键部位（脸、产品标志、文字要读的部分）。
- 深底浅字或浅底深字二者择一，不在同一块区域混用。

## 4. 阅读路径

三种可用路径，选一种，不要叠：

| 路径 | 写法 | 适用 |
| :--- | :--- | :--- |
| 中轴 | 标题在上、主体居中、信息在下 | 仪式感、正面展示 |
| Z 形 | 左上标题 → 右上主视觉 → 左下说明 → 右下页脚 | 信息较多的宣传图 |
| 对角 | 标题沿画面主斜线排，主体压在另一端 | 动感、冲突、演出类 |

画面里已有的线条（建筑边缘、道路、光束、人物视线）应当**顺着**阅读路径走；方向相反会让人读两遍。

## 5. 图文关系

- 标题可以沿主体的轮廓、建筑边缘或运动方向排列，但不得遮住关键内容。
- 标题与主视觉争同一块留白，是海报最常见的失效方式：要么给标题让位，要么把主视觉挪开，不要各占一半。
- 文字不要「贴」在主体上冒充纹理；要压图就给一层明确的底（色块、暗角、纸带）。

## 6. 边距与网格

- 至少保留一条一致的边距：四边等距，或上下不等但左右一致。
- 文字不贴边。贴边会被读成裁切事故，而不是设计。
- 两栏以上的信息区共用一条基线，不对齐的多栏看起来像没有排版。

## 7. 比例适配

| 比例 | 主体位置 | 标题区 |
| :--- | :--- | :--- |
| 16:9 横版 | 主体偏一侧，另一侧留环境 | 上三分之一或左下角 |
| 竖版海报 | 主体占中下，头部上方留空 | 上方四分之一 |
| 方形封面 | 主体居中或偏下 | 上方或下方带状 |

不要用「裁切思维」处理比例：竖版不是横版切一刀，主体和标题区都要重新安排。

## 8. 文字风险

- 模型生成文字不可靠，尤其多行、小字、非拉丁字符。**只规定文字区与气质，不指望一次到位**。
- 必须准确的文案（价格、地址、日期、品牌名）建议后期排版，或改用 Layout 精确落位（`core/layout.md`，实验性）。
- 有图内文字时负面去掉 `watermark` 与 `text`（`core/negative.md` §2）；字高估算见 `core/text-in-image.md` §2。

## 9. 反例

标题压在人脸上；两个同等权重的标题；文字贴边；四栏信息各自对齐；主视觉占满全幅没有标题区；用「排版精美」「高级感」代替具体位置。

## 10. 自检

1. 主标题层级是否唯一，且与主视觉共同承担第一眼？
2. 标题安全区是否低细节、低对比，且没压关键部位？
3. 阅读路径是否只有一条，画面线条是否顺着它？
4. 边距是否一致，文字有没有贴边？
5. 必须准确的文案，是否已说明「后期排版」或走 Layout？
